ODICOLOR : essais Samsung

TEST UNIQUEMENT — données synthétiques. Aucune donnée commerciale réelle à importer. L’application conserve son design et ses fonctions.

Ce guide n’ouvre aucune base et ne lit aucun fichier du téléphone. Les espaces A et B ont chacun leur stockage. Ne sélectionne que les fichiers téléchargés ici et les sauvegardes fabriquées pendant ce test.

1. Préparer Chrome

Ouvre ce lien dans Chrome du Dossier sécurisé Samsung, sans synchronisation commerciale. Reste dans cette instance pour tous les essais et les téléchargements. N’utilise pas la navigation privée. Aucun accès aux contacts, à l’appareil photo ou à la localisation n’est nécessaire.

2. Télécharger le petit jeu

Télécharger le jeu synthétique (~34 Ko)Attends la fin du téléchargement. Retrouve-le dans les téléchargements de cette instance Chrome.

3. Charger l’espace A

Ouvrir A — essais

Adresse A : __ORIGIN_A__. Vérifie qu’il n’y a aucun garage. Si des données apparaissent déjà, arrête et signale-le : ne les efface pas.

Dans l’application : Plus → Réglages → Sauvegarde. Sélectionne jeu-smoke.odicolor, touche Restaurer après contrôle, puis confirme. Attends le redémarrage.

4. Vérifier les données

  • 3 garages « GARAGE SYNTHETIQUE », 12 devis et 30 articles.
  • Ouvre chaque garage : son image porte le même numéro. Chaque garage a 20 visites, 10 notes et 5 besoins synthétiques.
  • Dans Catalogue, ouvre les catalogues PDF : les deux documents affichent « PDF SYNTHETIQUE 1 » et « 2 ».
  • L’article SYN-00001 coûte 10,00 € HT. Le premier devis : 30,03 € HT, 2,55 € de TVA et 32,58 € TTC.

Les « photos » sont des images SVG numérotées artificielles. Cela teste les pièces sauvegardées, pas encore la prise de vue ni les fichiers JPEG/HEIC de l’appareil photo.

5. Sauvegarder A

Dans Réglages → Sauvegarde, touche Télécharger une sauvegarde complète. Vérifie dans les téléchargements qu’un nouveau fichier odicolor-sauvegarde-….odicolor est présent et non vide. Note son nom ; il sera utilisé sur B. Ne partage aucune sauvegarde commerciale.

6. Restaurer dans B, vierge

Ouvrir B — restauration vierge

Adresse B : __ORIGIN_B__. Vérifie d’abord l’absence de garages, puis restaure le fichier exporté de A, et non le jeu initial. Refais tous les contrôles de l’étape 4. Ferme B et rouvre son lien : les pièces et les données doivent rester présentes.

7. Refuser une sauvegarde abîmée

Télécharge le fichier corrompu et le fichier tronqué. Sur B, essaie de les restaurer l’un après l’autre. Les deux doivent être refusés ; les données, images et PDF précédents doivent rester lisibles. Avec un fichier valide, annule ensuite la confirmation : aucun remplacement ne doit se produire.

8. Vérifier l’absence de mélange

Sur A uniquement, ajoute une note « NOTE TEST A ». Sur B, vérifie qu’elle est absente. Sur B, ajoute « NOTE TEST B », puis restaure à nouveau la sauvegarde de l’étape 5. La note B doit disparaître de l’état actif. Dans les copies de récupération, télécharge l’état précédent : le fichier doit être créé. Sa restauration complète demanderait une troisième destination vierge ; cet essai complémentaire reste à organiser.

9. Tester sans Internet

Avec Internet actif, ouvre A et B et laisse l’installation finir. Ferme tous leurs onglets puis rouvre chaque adresse une fois en ligne. Note ou mets en favoris ces deux liens.

Active le mode avion et vérifie que le Wi-Fi est désactivé. Ferme puis rouvre A et B depuis leurs favoris. Vérifie les garages, images, tarifs, historiques et les deux PDF. Sur B, crée une note « NOTE HORS LIGNE », télécharge une sauvegarde complète et vérifie le fichier. Restaure ensuite le fichier de l’étape 5, toujours sans Internet : la note hors ligne doit quitter l’état actif et les pièces rester lisibles.

Si le lancement échoue, note l’échec. Réactive Internet, attends une minute sur l’application puis referme et recommence. Le guide et ses téléchargements nécessitent Internet ; l’essai hors ligne porte sur A et B. Ne désinstalle rien et ne vide pas les données du navigateur.

10. Me transmettre le résultat

Réactive Internet. Indique ton modèle Samsung, Android, version de Chrome, puis pour chaque étape : réussi / échec / non testé. Ajoute le message exact ou une capture contenant exclusivement le jeu synthétique en cas d’échec. N’envoie aucune donnée réelle. Un essai non exécuté ne compte pas comme réussi.

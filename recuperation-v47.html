Récupération vers le code V47

Cette procédure ne diminue jamais une base v2 et n’efface aucune base. Elle crée une copie compatible v1 sur une origine ou un profil vierge, en conservant la base v2 et sa sauvegarde complète.

Réservé au retour de secours documenté. Le code V47 d’origine conserve les limites de fiabilité de son audit.

1. Exporter l’état complet de cette origine

Lecture seule des schémas 1 ou 2. Garde le fichier hors de cet appareil avant de changer de code.

2. Sur la destination vierge uniquement

Place ce kit avec le code V47 figé sur une autre origine isolée, ou dans un autre profil vierge. Ouvre cette page avant l’application V47.

Une destination contenant déjà des données sera refusée. Les archives et pièces jointes restent conservées, y compris celles que l’ancien code n’affiche pas.
